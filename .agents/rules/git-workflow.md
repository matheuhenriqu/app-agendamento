# Git Workflow Rules

- Sempre que concluir um conjunto de melhorias, correções ou alterações solicitadas pelo usuário, faça o commit com mensagem descritiva (Conventional Commits) e faça o push automaticamente para o repositório remoto do GitHub (`git push origin main`).
- Nunca versione arquivos de ambiente locais com segredos reais (como `.dev.vars` e `.env`).
